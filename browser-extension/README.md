# MAIL HUB 浏览器扩展

Chrome / Edge 浏览器扩展（Manifest V3），用于在注册场景下一键申领邮箱、自动提取验证码、完成后释放邮箱。

## 功能

- 🚀 **一键申领邮箱**：调用 MAIL HUB API 从邮箱池分配健康邮箱
- ⏳ **自动轮询结果**：后台每 2 秒查询任务状态，验证码到达后自动展示
- 📋 **一键复制**：复制邮箱地址、验证码/链接到剪贴板
- ✅ **完成并释放**：注册成功后标记任务完成，邮箱回到池中可被复用
- 🏷️ **项目隔离**：支持 `project_key`，同项目已成功的邮箱不会重复分配
- 🔔 **桌面通知**：验证码到达时弹出系统通知
- 📜 **任务历史**：本地保存最近 10 条任务记录

## 安装（开发者模式）

1. 打开 Chrome / Edge，进入 `chrome://extensions/`（Edge 是 `edge://extensions/`）
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录（`browser-extension/`）
5. 扩展安装成功，点击工具栏图标开始使用

## 配置

首次使用需要配置：

1. 点击扩展图标 → 「打开配置」（或右键扩展 → 选项）
2. **服务器地址**：你的 MAIL HUB 地址，例如 `http://127.0.0.1:8000`
3. **API Key**：在 MAIL HUB 后台 `backend/data/.api_key` 文件中获取
4. **默认邮箱池 ID**（可选）：留空使用默认池
5. 点击「保存配置」→「测试连接」确认连通

## 使用流程

1. 在注册页面需要邮箱时，点击扩展图标
2. （可选）填写项目 Key、匹配发件人/主题
3. 点击「一键申领邮箱」
4. 复制分配到的邮箱地址，填入注册页面
5. 点击发送验证邮件，扩展会自动轮询等待
6. 验证码到达后自动展示，点击「复制结果」
7. 填入验证码完成注册
8. 点击「✅ 完成并释放」，邮箱回到池中

## 注意事项

- 扩展需要 MAIL HUB 后端 v1.1.0+ 版本（支持 `/api/v1/system/version` 和 `/claim-complete` 接口）
- API Key 存储在浏览器同步存储中，请确保浏览器已登录同步
- 任务默认超时 5 分钟，超时后自动标记为 TIMEOUT
- 图标为程序生成的简易版本，可自行替换 `icons/` 目录下的 PNG 文件
